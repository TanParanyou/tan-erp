# tan-erp

`tan-erp` คือระบบ Project ERP สำหรับธุรกิจออกแบบ ตกแต่งภายใน และผลิตงานบิวต์อิน เริ่มต้นจากงานประเมินราคา (Estimate) แล้วค่อยขยายไปสู่งานขาย โครงการ จัดซื้อ คลัง ผลิต ติดตั้ง การเงิน และบริการหลังการขาย

สถานะปัจจุบันคือ **Documentation Foundation**: วางคำศัพท์ ขอบเขต กฎ สถาปัตยกรรม และ Flow ก่อนเริ่มสร้างระบบจริง

## หลักสำคัญ

- ระบบนี้คือ **ERP** ไม่ใช่ MRP; MRP เป็นโมดูลในอนาคต
- ภาษาไทยเป็นค่าเริ่มต้น และรองรับภาษาอังกฤษ
- Backend เป็นผู้ตัดสินสิทธิ์ RBAC และขอบเขตข้อมูล
- เริ่มแบบ Modular Monolith เพื่อดูแลง่ายและแยกบริการได้เมื่อมีเหตุผลจริง
- เอกสาร Markdown เป็นแหล่งอ้างอิงหลัก ส่วน HTML Portal เป็นมุมมองภาพจาก JSON

## ขอบเขตของ Repository ตอนนี้

มีเฉพาะเอกสาร แผนผัง JSON ภาพ SVG และโปรแกรมดูเอกสารแบบ Static เท่านั้น ยังไม่มี Frontend/Backend ของ ERP และยังไม่มีฐานข้อมูล
