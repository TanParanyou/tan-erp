# G-15 Thai Tax (VAT, WHT, Retention, Tax Invoice/Receipt PDF, Credit/Debit Note) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `.agents/skills/tiered-orchestration/SKILL.md` to implement this plan phase-by-phase.

**Goal:** ขยายโมดูล Finance (`CP-15`) ให้รองรับภาษีมูลค่าเพิ่ม (VAT 7% จาก `TaxPolicyVersion` พร้อมแยกฐานภาษีต่อบรรทัด), ภาษีหัก ณ ที่จ่าย (WHT พร้อมเลขที่หนังสือรับรอง 50 ทวิ ตอนรับชำระ), เงินประกันผลงาน (Retention % หักตอนวางบิลและปลดเมื่อหมดระยะประกัน `CP-14`), ใบกำกับภาษี/ใบเสร็จรับเงิน PDF (ผ่าน QuestPDF `G-04`), และใบลดหนี้/ใบเพิ่มหนี้ (Credit Note / Debit Note อ้างอิงใบแจ้งหนี้เดิม พร้อม Maker–Checker + Approval Authority `G-03c`)

**Architecture:** Clean Architecture (`Domain` → `Application` → `Infrastructure` → `Api`) + Next.js App Router (`frontend/src/features/finance/`)

---

## 1. กฎธุรกิจและค่าเริ่มต้น (`TEST_ONLY`)

1. **VAT 7% (Versioned Tax Policy & Line Tax Base):**
   - เมื่อสร้าง `BillingDocument` สามารถส่งรายการบรรทัด (`Lines: BillingLineInput[]` optional) หรือระบุยอดรวม (`Amount`) พร้อมเลือกเปิดคิด VAT (`ApplyVat: bool`, ค่าเริ่มต้น `false` เพื่อรักษาความเข้ากันได้ย้อนหลังกับ `CP-15` 100%) หรือระบุ `VatRate` (หาก `ApplyVat = true` และไม่ระบุ `VatRate` ระบบดึง `TaxRate` จาก `TaxPolicyVersion` ที่ Active ขององค์กร หรือ fallback เป็น `0.07m` `TEST_ONLY`)
   - ปัดเศษภาษีมูลค่าเพิ่มด้วย `MidpointRounding.AwayFromZero` ทศนิยม 2 ตำแหน่ง: `VatAmount = decimal.Round(TaxBaseAmount * VatRate, 2, MidpointRounding.AwayFromZero)`
   - เมื่อมี VAT (`VatRate > 0` หรือ `ApplyVat = true`) ระบบรันเลขใบกำกับภาษี `TaxInvoiceNumber` (`TIV-{YYYY}-{SEQ:4}`) อัตโนมัติ
2. **Retention (เงินประกันผลงานผูกสัญญาและการรับประกัน `CP-14`):**
   - ระบุ `RetentionRate` (`0 .. 0.30`, เช่น `0.05` = 5%) ตอนออกใบแจ้งหนี้
   - `RetentionAmount = decimal.Round(Amount * RetentionRate, 2, MidpointRounding.AwayFromZero)`
   - `RetentionStatus`: `"none"` (เมื่อ `RetentionAmount == 0`), `"held"` (เมื่อหักเงินประกันไว้), `"released"` (เมื่อปลดเงินประกันหลังหมดระยะเวลาประกัน)
   - ยอดที่เรียกเก็บได้ก่อนปลด Retention: `EffectiveReceivable = Amount + VatAmount + DebitNoteAmount - CreditNoteAmount - (RetentionStatus == "held" ? RetentionAmount : 0m)`
   - การปลด Retention (`POST /api/v1/billings/{id}/release-retention` + `If-Match`): ตรวจสอบว่าโครงการมีใบรับประกัน (`Warranty` จาก `CP-14`) ที่วันสิ้นสุด (`EndDate`) ผ่านพ้นไปแล้ว (`EndDate < Today`); หากไม่มีใบรับประกันหรือยังไม่หมดประกัน คืน `409 RETENTION_WARRANTY_NOT_EXPIRED`
   - การปลด Retention ไม่เพิ่มยอดวางบิลตามสัญญา (`Billed` คงเดิม) จึงไม่ทำให้ยอดวางบิลเกิน `BaselineContractAmount`
3. **Withholding Tax (WHT หัก ณ ที่จ่าย & หนังสือรับรอง 50 ทวิ):**
   - เมื่อบันทึกรับชำระ (`POST /api/v1/billings/{id}/payments`) รองรับ `WhtRate` (`0 .. 0.30`, เช่น `0.01`, `0.02`, `0.03`, `0.05`), `WhtType` (เช่น `"service_3"`, `"transport_1"`, `"advertising_2"`, `"rent_5"`) และ `WhtCertificateNumber` (เลข 50 ทวิ ≤ 100 ตัวอักษร; บังคับกรอกเมื่อ `WhtRate > 0` มิฉะนั้นคืน `422 PAYMENT_WHT_CERTIFICATE_REQUIRED`)
   - `WhtAmount = decimal.Round(Amount * WhtRate, 2, MidpointRounding.AwayFromZero)` และ `NetCashReceived = Amount - WhtAmount` (โดย `Amount` คือยอดตัดหนี้ใบแจ้งหนี้ และรันเลขใบเสร็จ `ReceiptNumber` `RCT-{YYYY}-{SEQ:4}`)
4. **Credit Note (`CN`) & Debit Note (`DN`):**
   - สร้างผ่าน `POST /api/v1/billings/{id}/notes` (`Idempotency-Key`, permission `billings.manage`): `{ noteType: "credit" | "debit", reason, taxBaseDelta }`
   - รันเลขเอกสาร `CN-{YYYY}-{SEQ:4}` หรือ `DN-{YYYY}-{SEQ:4}`
   - คำนวณ `VatDelta = decimal.Round(taxBaseDelta * billing.VatRate, 2, MidpointRounding.AwayFromZero)` และ `TotalDelta = taxBaseDelta + VatDelta`
   - Invariant สำหรับ Credit Note: ห้ามลดหนี้เกินฐานภาษีคงเหลือของใบแจ้งหนี้ (`taxBaseDelta <= billing.Amount + billing.DebitNoteBaseAmount - billing.CreditNoteBaseAmount`) และห้ามทำให้ยอดสุทธิต่ำกว่ายอดที่รับชำระแล้ว (`EffectiveReceivableAfterCredit >= billing.PaidAmount`) มิฉะนั้นคืน `422 BILLING_NOTE_EXCEEDS_ORIGINAL`
   - อนุมัติผ่าน `POST /api/v1/billings/{id}/notes/{noteId}/approve` (`If-Match`, permission `billings.manage`): บังคับ Maker ≠ Checker (`409 BILLING_NOTE_SELF_APPROVAL`) และตรวจวงเงินอนุมัติผ่าน `IApprovalAuthority` (`ApprovalDocumentType.ChangeOrder`)
   - ส่งเข้า `AccountingOutbox` (`billing-note.approved`)
5. **Tax Invoice / Receipt PDF (`G-04` QuestPDF):**
   - `GET /api/v1/billings/{id}/tax-document/pdf` (permission `billings.read`): สร้างไฟล์ PDF A4 ภาษาไทย/อังกฤษ แสดงข้อมูลผู้ขาย (Tax ID/Branch), ข้อมูลโครงการ/ลูกค้า, ตารางรายการ/ฐานภาษี, VAT, เงินประกันผลงาน (Retention), ใบลดหนี้/ใบเพิ่มหนี้ที่อนุมัติแล้ว, และประวัติการรับชำระพร้อมยอดหัก ณ ที่จ่าย (50 ทวิ)
