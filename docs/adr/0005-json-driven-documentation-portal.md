# Markdown และ JSON-driven Documentation Portal

Markdown เป็นแหล่งอ้างอิงหลัก ส่วน Static HTML Portal แสดงแผนผังจาก JSON และ Local SVG โดยไม่มี Framework หรือ External Dependency วิธีนี้ทำให้คนธุรกิจเห็นภาพและนักพัฒนาแก้ข้อมูลแบบ Version-controlled ได้ แต่ Portal ต้องเปิดผ่าน Local HTTP Server เพราะ Browser จำกัดการโหลด JSON จาก `file://`
