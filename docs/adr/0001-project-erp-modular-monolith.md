# Project ERP บน Modular Monolith

ระบบถูกนิยามเป็น Project ERP ซึ่งเริ่มจาก Estimation และขยายเป็น Project, Procurement, Inventory, Production/MRP, Installation และ Finance Integration เราเลือก Modular Monolith ระยะแรก เพราะ Boundary ยังต้องเรียนรู้และทีมยังไม่ต้องแบกความซับซ้อนของ Distributed System; Module ต้องแยก Ownership ชัดเพื่อเปิดทางแยก Service เมื่อมีหลักฐานด้านทีม การ Scale หรือการ Deploy
