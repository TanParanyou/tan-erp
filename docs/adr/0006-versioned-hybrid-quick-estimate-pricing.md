# Quick Estimate ใช้ Versioned Hybrid Pricing

Quick Estimate คำนวณช่วงราคาด้วย Pricing Template Version ซึ่งประกอบด้วย Measurement Rule, Reference Rate, Factor และ Risk Range ส่วน Official Estimate ต้องคำนวณต้นทุนและราคาทางการใหม่ เราเลือกแนวทาง Hybrid นี้แทนการแตกต้นทุนละเอียด ณ หน้างานหรือใช้ Formula อิสระ เพราะต้องรักษาความเร็ว ความปลอดภัย และการคำนวณย้อนหลัง; ผลที่ตามมาคือ Template ต้องมี Lifecycle, Calibration, Approval และ Calculation Snapshot
