# แยก Cost Source ที่ใช้ซ้ำจากหลักฐานราคาของ Cost Record

Cost Source เป็นรายการแหล่งต้นทุนระดับ Organization ที่เลือกใช้ซ้ำได้ ส่วนเลขอ้างอิง เหตุผล และ Verified Evidence File เป็นข้อมูลของ Cost Record แต่ละฉบับ เพราะหลักฐานราคาต้องคงตามรุ่นและ Estimate Snapshot แม้ผู้ดูแลแก้ชื่อหรือปิดใช้ Source ภายหลัง ทางเลือกที่เก็บเอกสารอ้างอิงไว้บน Source จะทำให้ราคาหลายฉบับพึ่งหลักฐานชุดเดียวและแก้ย้อนหลังโดยไม่ตั้งใจ รอบแรกสร้าง Source ชนิด Manual เท่านั้น; Source เก่าที่ระบุชนิดไม่ได้เป็น `legacy` แบบอ่านย้อนหลังได้แต่เลือกใหม่ไม่ได้ Supplier และชนิดอื่นต้องมี Contract/Governance ก่อนเพิ่ม
