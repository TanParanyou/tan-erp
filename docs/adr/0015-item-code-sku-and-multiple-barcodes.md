# Item Code เป็น SKU ภายใน และ Barcode เป็นความสัมพันธ์หลายค่าต่อ Item

Item มี `id` เป็นตัวตนถาวรและ `code` เป็นรหัสภายในองค์กร; สำหรับสินค้าที่ซื้อหรือเก็บคลัง `code` เดียวกันเป็น SKU. เราไม่เพิ่ม `sku` อีกคอลัมน์ เพราะสองรหัสภายในที่มีความหมายเดียวกันทำให้การค้นหา เอกสาร และการย้ายข้อมูลเลือกตัวจริงไม่ตรงกัน. Barcode/GTIN มีหน่วยและระดับบรรจุของตนเอง จึงอยู่ใน `item_barcodes` แบบหนึ่ง Item ต่อหลายรหัส ไม่ยัดเป็นคอลัมน์บน Item; Supplier Part Number, Lot/Serial และ BOM เป็นข้อมูลของโมดูลเจ้าของแยก. การเลือกนี้รักษา `Item.code` และ Estimate Snapshot เดิมไว้ แต่ต้องเพิ่ม migration, uniqueness และ scan lookup ก่อนใช้กับคลัง
