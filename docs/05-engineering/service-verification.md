## ข้อจำกัด

ค่าเริ่มต้นรอ Installation/Customer Service และ Business ยืนยัน: ไม่มีไฟล์แนบ/หลักฐานภาพ (ตามแผนที่ให้ใช้ shared file access) ใน checklist/ข้อบกพร่อง/ส่งมอบ, ไม่มีลายเซ็นลูกค้าตอนส่งมอบ (บันทึกชื่อผู้รับมอบโดยเจ้าหน้าที่), ไม่มีปฏิทินกำลังคน/มอบหมายพนักงาน/จัดสรรทีม, ไม่มีเงื่อนไขประกันตามสินค้า/ชิ้นส่วน/การต่อ/ยกเลิกประกัน, ไม่มีค่าบริการ/ใบเสนอราคางานนอกประกัน/การชดเชย, ไม่ผูกกับ Work Order/ผลผลิตของ Production, ไม่มีการแจ้งเตือน/SLA, ไม่ได้ทดสอบ race ของคำสั่งพร้อมกัน (อาศัย row version), ไม่ได้รัน full Integration suite, `next build`, Playwright; ต้องมอบ 7 สิทธิ์ใหม่ (`installations.*`, `warranties.read`, `service-requests.*`) ให้ Role จริง.
