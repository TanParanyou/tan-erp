# Business Glossary (คำศัพท์ธุรกิจ)

แหล่งอ้างอิงคำศัพท์หลักอยู่ที่ [CONTEXT.md](../../CONTEXT.md) เพื่อป้องกันนิยามซ้ำและคลาดเคลื่อน

## คำที่มักสับสน

| คำ | ความหมายสั้น ๆ | ไม่ใช่ |
| --- | --- | --- |
| Estimate | การคำนวณภายใน | Quotation ที่ส่งลูกค้า |
| Quotation | ข้อเสนอเชิงพาณิชย์ | Invoice หรือใบแจ้งหนี้ |
| Item Master | ข้อมูลมาตรฐานที่นำกลับมาใช้ | รายการงานเฉพาะโครงการ |
| Permission | สิ่งที่ผู้ใช้ทำได้ | Role หรือขอบเขตข้อมูล |
| Scope | ข้อมูลส่วนใดที่สิทธิ์ครอบคลุม | สิทธิ์ในการกระทำ |
| ERP | ระบบบริหารกระบวนการองค์กร | MRP เพียงโมดูลเดียว |

เมื่อเกิดคำใหม่หรือความหมายเปลี่ยน ให้แก้ `CONTEXT.md` ก่อน แล้วจึงปรับเอกสารและ JSON Flow ที่เกี่ยวข้อง
